What I'd fix without asking, if you agree

  • Lenient prefix strip — clears 8 products at once (the five Universal braces, Neoprene Hinged, Ovation Post Op Square Toe, Gauze Sponges Sterile). Today the product name is only removed from a SKU name when it matches exactly; matching on whole words instead handles "Universal TLSO 456, 4XL" and "…Support Hinged".
  • Size ranking for 3XL/4XL/5XL — one line; they currently sort before Large because "3X-Large" only matches the word "large".
  • Straight vs curly quotes — normalise before comparing, which restores the Nu-Form 0637 picker.

What I can't decide for you

  • Compact Pro ROM ×2 — what actually separates 51500 from 51508, and 51600 from 51608?
  • Game Changer — confirm the under-sleeves are accessories, so I move them to Related products.
  • Extension belt — is 61000-210 a 10-pack of 61000-2?
  • Gauze Sponges Non-Sterile — one SKU claims two sizes. Which is right?
  • Ovation Square Toe Post-Op Shoe — one SKU has no option text at all.
